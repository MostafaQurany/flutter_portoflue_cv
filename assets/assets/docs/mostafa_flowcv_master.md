## Featured Backend Case Study
### Koolyum | Backend Engineer - Universal POS Bridge and AI Online Ordering Workflow

#### Short Description
Koolyum is a multi-service backend platform built for AI-assisted online ordering, tenant-aware POS integration, guest checkout, and operational order management.

#### My Role
My role focused on shaping backend-connected flows that link ordering, checkout, workflow handling, and provider integration into one dependable system. I worked on service contracts, order lifecycle behavior, AI-supported cart flow, and live update patterns that made the ecosystem usable from both the customer-facing side and the internal operations side.

#### Contribution Highlights
- Designed or extended tenant-scoped API contracts and provider resolution flows across the bridge layer.
- Worked on MongoDB-backed order workflow records with guarded state transitions, retry eligibility, and safe provider creation rules.
- Supported checkout cart APIs and AI sync behavior using `chatroom_id` plus full item payload persistence.
- Connected WebSocket event flows so cart and workflow clients can receive live updates without repeated polling.
- Integrated source-backed service behavior into one backend story spanning ordering, provisioning, Odoo tenant scope, and vector search.

#### Architecture Notes
- Public integration is tenant-scoped through `X-API-Key` and `X-Tenant-Id` instead of exposing provider credentials to clients.
- The bridge separates direct provider order creation from local MongoDB workflow resources so operational state stays under internal control.
- Guest checkout carts are stored independently from `orders_events` and are identified by `chatroom_id` for AI and frontend reuse.
- Redis is used for cache and synchronization behavior, while MongoDB stores workflow and cart records.
- The provisioning service is admin/internal oriented and guarded by feature flags.
- The custom Odoo layer enforces tenant/company scope and publishes product changes to the AI and embedding pipeline.

#### Technologies
Python, FastAPI, MongoDB, Redis, WebSockets, Qdrant, Docker, Node.js, Express, Mongoose, Odoo, Traefik, Multi-tenant Architecture, POS Integration, API Design, Workflow and State Machine Design
